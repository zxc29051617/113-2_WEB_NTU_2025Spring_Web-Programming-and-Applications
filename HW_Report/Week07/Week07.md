# Week07 Homework Report

>本次作業同樣是為期中期末專案做準備，主題與上次同樣為 **「咖啡廳地圖 CoffeeSeeker」** ，旨在延伸 google map 的查詢功能。除了原本的客製選項，加入聊天機器人輔助尋找咖啡店，以及在事前建立好資料庫供 AI 參考，讓有選擇障礙的使用者輕鬆找到最符合需求的咖啡店。 地圖外觀顯示方面串接 **google map API** ；聊天機器人則預計使用如 **Week03,Week05** 作業中用到之 **Gemini API** ；資料庫則持續以爬蟲地毯式搜集的台大周圍的咖啡廳(此"周圍"的距離隨免費API額度持續更新中)。  

>本週除了續用之前的 **HTML** 、 **CSS** 配合 **React** 開發及外觀功能優化，也跟隨上課進度實作了 **Django** 的後端管理系統及 **docker** 環境整合。除了優化與增加已完成的 **google map** 外觀環境建置選項及細節(新增很多選項及新功能，如條件選擇及機器人動態生成對話框等)，也建立了後端 **Django** 的資料庫管理登入介面。此外，前端及後端都被整合進 **docker image** ，無須 **git** 或安裝其他套件便能在本機開啟服務。預計期末專案可以將之前設計好的聊天機器人內容及資料庫串接、順便加入其他後續上課教到的相關內容。

- 使用設置：

    0. **Github** 中主要為前端設計內容，其他後端設計皆在 **docker image** 中。為方便操作(且專案複雜度不大)，本次作業將前後端整合於單一 **docker image** 中，以方便後續連線及助教批改。請確保本機能容下約 **500MB** 的 **image file** ，並確任 **port** 8888 沒有同時被其他專案占用，否則可能須更改下步驟的 **port** 參數。
    1. 首先確保 **docker login** 成功，接著便執行下指令下載映像檔
    ```sh
        docker pull rickychiang2003/web2025_ubuntu2204:v0.3
    ```
    2. 下載完後開啟 **container** 。注意預設指令中指定本機 **port 8888** 與開啟 **container** 的 **port 8080** 相接，若本機  **port 8888** 已被占用，則將後續所有 **8888** 改成一固定的空閒 **port** 值
    ```sh
        docker run -it -p 8888:8080 rickychiang2003/web2025_ubuntu2204:v0.3
    ```
    3. 若成功開啟則可以移動至其中的專案目錄 **2025web** 下，並根據後續步驟分別開啟(測試)服務。若 **ls** 可以發現，所有批改相關檔案皆在此資料夾下， **CoffeeSeeker** 為前端設計內容，其他檔案及資料夾則為後端設計內容。
    ```sh
       cd /2025web
       ls -l
    ```
    4. 先測試前端外觀設計，直接執行已建立好的服務指令後於本機的瀏覽器上開啟 **localhost:8888** 。 ***注意，應看到 GoogleMap API 建構的背景、上方橫排搜尋列、及右下角的 AI 聊天窗口。若有遺漏或部分空白，建議您開啟無痕、重開瀏覽器或檢查電腦定位資訊，因為 GoogleMap API 時常因當下定位問題導致卡頓沒顯示出來。***
    ```sh
        cd /2025web/CoffeeSeeker
        npm run dev -- --port 8080
    ```
    5. 接著測試後端管理系統，執行服務後便能於本機瀏覽器上開啟 **localhost:8888/admin** ，其中已設定了完善的帳號管理與搜索機制。目前唯一的系統管理帳號為 **Team25** ，密碼為 **25252525** ，可以登入以查看本次完成設定的功能，也可以嘗試註冊與搜索帳號。
    ```sh
        cd /2025web
        python3 manage.py runserver 0.0.0.0:8080
    ```
    6. 若步驟 4. 與 5. 的內容與報告不同或出現問題，請來信詢問或確認其他相關設定是否一致。
